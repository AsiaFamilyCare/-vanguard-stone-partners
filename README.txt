STONE VAULT PROTOTYPE

This is a distributor-ready demo storefront with:
- Product categories
- Demo inventory statuses (In Stock / Low Stock / Out of Stock)
- Filtering and sorting
- Add-to-cart functionality using localStorage
- Distributor partnership section
- Responsive mobile/desktop design
- Architecture ready to replace demo product data with a supplier feed later

IMPORTANT:
- Product names, prices, inventory, contact details, and photos are demo placeholders.
- Checkout is intentionally demo-only. Connect Square, Shopify, Stripe, WooCommerce, or another commerce backend before accepting real orders.
- Replace the brand name "Stone Vault" if you want a different business name.

To preview locally, open index.html in a browser.
